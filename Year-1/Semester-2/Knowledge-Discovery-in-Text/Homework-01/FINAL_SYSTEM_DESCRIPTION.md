# Финално описание на системата

Разработката е фокусирана върху английските въпроси. Допълнително е добавена поддръжка за данните от BhashaBench-Finance, като за експериментите са използвани само английските MCQ въпроси.

## Данни и предварителна обработка

Първата стъпка е нормализиране на входните данни до общ JSONL формат. За всеки пример се извличат текстът на въпроса, възможните отговори, буквите на опциите и правилният отговор, когато е наличен за локална оценка. При FinMMEval беше добавена по-устойчива логика за зареждане на английските данни, тъй като публичният набор има несъответствия в схемата между различните езикови файлове. За BhashaBench-Finance беше приложено филтриране само до английски въпроси от тип MCQ.

Локалната оценка е направена с разделяне train/dev при `seed=42` и `dev_size=0.2`. За BhashaBench-Finance това дава 12 440 заредени MCQ примера, от които 9 952 за обучение и 2 488 за dev оценка.

## Тествани подходи

Бяха реализирани и сравнени няколко подхода:

- базов модел, който избира най-често срещаната буква;
- лексикален baseline чрез overlap между въпроса и опциите;
- supervised pair модели, при които всеки въпрос се превръща в няколко двойки `(question, option)`;
- TF-IDF + Logistic Regression;
- TF-IDF + SVM;
- MLP върху TF-IDF/SVD представяния;
- Word2Vec + MLP;
- 4D multiclass SVM;
- transformer cross-encoder;
- fine-tuning на `meta-llama/Meta-Llama-3-8B-Instruct` с QLoRA.

При pair моделите всяка опция се оценява отделно като вярна или грешна, а при inference се избира опцията с най-висок резултат. За Llama 3 беше използван QLoRA подход с 4-bit quantization, LoRA ранг 16, `bf16`, gradient checkpointing и greedy generation. Моделът генерира кратък отговор, който се нормализира до избрана опция.

## Резултати

Основната метрика е exact match accuracy, която съвпада с top-1 accuracy, защото системата избира един финален отговор за всеки въпрос.

| Модел | Dev въпроси | Exact match / Top-1 |
|---|---:|---:|
| most common letter baseline | 2488 | 0.2641 |
| lexical overlap | 2488 | 0.2408 |
| TF-IDF + Logistic Regression pair | 2488 | 0.3127 |
| SVM pair | 2488 | 0.3131 |
| MLP pair | 2488 | 0.2769 |
| Word2Vec + MLP pair | 2488 | 0.3031 |
| 4D multiclass SVM | 2488 | 0.2850 |
| Transformer cross-encoder | 2488 | 0.2834 |
| Llama 3 8B Instruct + QLoRA | 2488 | 0.4964 |

Най-добрият резултат е постигнат от `meta-llama/Meta-Llama-3-8B-Instruct` след QLoRA fine-tuning: **0.4964 exact match accuracy** върху dev частта на английския BhashaBench-Finance MCQ набор. Сред класическите модели най-добър е SVM pair моделът с **0.3131 accuracy**, много близо до TF-IDF + Logistic Regression pair модела с **0.3127**.
